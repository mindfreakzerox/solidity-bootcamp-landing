# Solidity Bootcamp Landing

Next.js static landing page for the Solidity Bootcamp. Highlights curriculum, instructors, pricing, and FAQs. No backend or external services.

## Run
```
pnpm install
pnpm dev
```

## Build/Export
```
pnpm build
pnpm next export
```

Features:
- Hero with CTA and outcomes
- Curriculum by track
- Instructor highlights
- Pricing/apply section
- FAQs
- Responsive, gradient UI
